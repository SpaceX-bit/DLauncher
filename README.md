**DLauncher** — это [краткое описание: например, «лёгкий и быстрый лаунчер для Minecraft с поддержкой Forge, Fabric и модпаков»].

> ⚠️ **Поддерживаемые платформы: Windows и Linux.** macOS не поддерживается.

## ✨ Возможности

- 🚀 Быстрый запуск Minecraft [укажи версии, например 1.8–1.21]
- 🧩 Поддержка **[Forge / Fabric / Quilt / NeoForge]**
- 📦 Установка модпаков в один клик
- 👤 Управление несколькими профилями игроков
- 🎨 [Свой пункт: тёмная тема / кастомный скин / портативность и т.д.]
- 🔄 Автообновление лаунчера

## 💻 Поддерживаемые ОС

| Платформа | Статус | Файл релиза |
|-----------|--------|-------------|
| 🪟 Windows 10/11 | ✅ Поддерживается | `DLauncher.exe` |
| 🐧 Linux (x64) | ✅ Поддерживается | `DLauncher-x.x.x-linux.tar.gz` |
| 🍎 macOS | ❌ Не поддерживается | — |

## 📥 Скачать

Готовые сборки доступны в разделе [**Releases**](https://github.com/SpaceX-bit/DLauncher/releases).

**🪟 Windows**

1. Скачай `DLauncher.exe` из последнего релиза
2. Запусти файл — установка/запуск не требует дополнительных действий
3. Если Windows SmartScreen показывает предупреждение (файл без цифровой подписи), нажми **«Подробнее» → «Выполнить в любом случае»**

> 💡 Java устанавливать не нужно — она уже встроена в `.exe`.

**🐧 Linux**

```bash
tar -xzf DLauncher-x.x.x-linux.tar.gz
cd DLauncher
chmod +x DLauncher
./DLauncher
