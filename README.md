# DLauncher

Лаунчер для Minecraft на Electron.

## Запуск

1. Установи [Node.js](https://nodejs.org) (18+). Java ставить не нужно — лаунчер скачает её сам.
2. Фон лежит в `background.jpg` рядом с `index.html` — замени файл, чтобы сменить картинку.
3. В папке проекта:

```
npm install
npm start
```

## Сборка .exe

Двойной щелчок по **build-exe.bat** (нужен только Node.js). Через несколько минут в папке `dist` появятся:

- `DLauncher-<версия>-x64-portable.exe` — один файл, работает без установки (сам не обновляется);
- `DLauncher-<версия>-x64-nsis.exe` — мастер установки (умеет автообновление), подробности ниже;
- `latest.yml` — файл для автообновления (см. ниже).

Сборка только под **64-разрядную Windows (x64)**; Java для игры тоже скачивается 64-битная. На 32-битной Windows лаунчер не запустится (современный Minecraft там и не работает).

Если сборка падает с ошибкой про "symbolic link" — включи Режим разработчика в Windows или запусти `build-exe.bat` от имени администратора.

## Что умеет

- **Профили.** У каждого профиля своя версия игры, загрузчик и своя папка `instances/<профиль>` (моды, ресурспаки, шейдеры, миры, настройки). Вкладка «Профили», выбор профиля — внизу рядом с «ИГРАТЬ».
- **Настройки профиля** (кнопка «Настроить» на карточке): своя память (или общая из настроек), аргументы Java, размер окна или полный экран, свой путь к Java.
- **Серверы профиля** (кнопка «Серверы» внизу и на карточке): добавление по адресу, избранное, онлайн, пинг и описание сервера, значок сервера, кнопка «Зайти» на любой сервер. «Импорт из игры» подтягивает серверы из `servers.dat`, добавленные в самой игре.
- **Liquid Glass** (Настройки → Оформление): стеклянные панели с размытием, бликами по краям и лёгким преломлением фона. Включается и выключается галочкой, сила настраивается ползунком.
- **Импорт из других лаунчеров.** При запуске лаунчер ищет сборки в Prism Launcher / PolyMC / MultiMC, приложении CurseForge, Modrinth App, Legacy Launcher (и TLauncher) и официальном лаунчере Minecraft и предлагает перенести их. Файлы (моды, ресурспаки, шейдеры, настройки, список серверов, по желанию миры) копируются в новые профили, а в старых лаунчерах ничего не меняется. Позже импорт можно открыть кнопкой во вкладке «Профили».
- **Версии:** релизы, снапшоты, бета и альфа. **Загрузчики:** Vanilla, Fabric, Quilt, Forge, NeoForge (1.20.2+).
- **Установленные моды** (вкладка «Установлено»): названия и иконки из Modrinth, включить/выключить (файл получает суффикс `.disabled`), удалить, обновить один или все моды.
- **Сборки** (вкладка «Моды» → «Сборки»): Modrinth (`.mrpack`) и CurseForge. Сборка ставится как новый профиль: версия игры, загрузчик, моды, ресурспаки и настройки.
- **Вход через Microsoft** (Настройки → Аккаунт), можно добавить до 10 аккаунтов и выбирать, под каким заходить в игру; или офлайн по нику.
- **Быстрый вход на сервер:** лаунчер запоминает последний сервер профиля (по логу игры) и показывает кнопку «На сервер: адрес» рядом с «ИГРАТЬ».
- **Автообновление** лаунчера (установленная версия, см. ниже).
- **Язык интерфейса** (Настройки → Оформление → «Язык / Language»): русский и английский. Язык переключается сразу, окно перезагружается само. Названия профилей, модов и сборок остаются как есть.
- **Свой фон** (Настройки → Оформление → «Фон лаунчера»): любая картинка (PNG, JPG, WEBP, GIF, BMP, AVIF, до 100 МБ) или видео (MP4, WEBM, M4V, OGV, MOV, до 1 ГБ). Файл копируется в папку данных лаунчера, так что его можно потом перемещать или удалять. Видео идёт без звука по кругу и ставится на паузу, пока игра запущена или окно свёрнуто. Ползунок «Затемнение фона» делает текст читаемее на ярких фонах. «Сбросить фон» возвращает стандартный.
- **Тестировщик:** мелкая кнопка рядом с «О разработчике» открывает карточку с именем Hiho и кнопкой TikTok (ссылка открывается в браузере). Адрес зашит в `main.js` (`LINKS`), из интерфейса его подменить нельзя.
- **Discord Rich Presence** (Настройки → Discord): в статусе видно, что ты в лаунчере, запускаешь игру или играешь, с версией, загрузчиком и именем профиля и со временем игры.
- Java скачивается автоматически (Eclipse Temurin) под нужную версию Minecraft.
- «Оптимизация»: набор модов для FPS, сначала Modrinth, затем CurseForge (нужен API-ключ).
- Иконки грузит сам лаунчер (кэш на диске, запасной путь через wsrv.nl) — VPN не нужен.
- Моды, ресурспаки и шейдеры с Modrinth и CurseForge, память, путь к Java.

## Вход через Microsoft

Microsoft разрешает входить в Minecraft только приложениям, которые зарегистрированы и одобрены. Своё приложение нужно завести один раз:

1. Зайди на [portal.azure.com](https://portal.azure.com) → **Microsoft Entra ID** → **App registrations** → **New registration**.
2. Название любое; тип аккаунтов — **Personal Microsoft accounts only** (или «…and organizations»).
3. В разделе **Authentication** включи **Allow public client flows** (Yes) и сохрани.
4. Скопируй **Application (client) ID** и вставь в Настройки → Аккаунт → «Client ID приложения Azure», режим — Microsoft, затем «Добавить аккаунт». Аккаунтов можно добавить несколько: у активного стоит отметка, остальные включаются кнопкой «Выбрать», «Удалить» работает в два нажатия. Аккаунт из прошлой версии переносится сам.
5. Если после входа Minecraft отвечает ошибкой 403 — приложение ещё не одобрено Mojang. Заявка подаётся через форму: https://aka.ms/AppRegInfo (обычно ждать приходится несколько дней). Пока заявка не одобрена, пользуйся офлайн-режимом.

Токены хранятся в `account.json` в папке данных приложения; refresh-токен шифруется средствами Windows (safeStorage).

## Мастер установки (`…-nsis.exe`)

Обычный установщик Windows с пошаговыми окнами, на языке системы (русский или английский):

1. **Для кого ставить:** только для меня (без прав администратора) или для всех пользователей компьютера (Program Files, Windows спросит разрешение).
2. **Диск и папка:** «Обзор» позволяет выбрать любой диск (C:, D:, E: и т. д.) и любую папку. Имя `DLauncher` в конце пути подставится само. На неосновных дисках лучше выбирать подпапку, например `D:\Games`, а не корень диска: в корень без прав администратора Windows иногда не даёт писать.
3. **Параметры:** показывается итоговая папка и галочка «Создать ярлык на рабочем столе» (по умолчанию включена). Ярлык в меню «Пуск» создаётся всегда.
4. **Установка** и последний экран с галочкой **«Запустить DLauncher»**.

Автообновление ставит новую версию в ту же папку и ничего не спрашивает. Удалить лаунчер можно через «Параметры → Приложения»; папка с твоими профилями, модами и мирами (корневая папка лаунчера в настройках) при этом остаётся.

Шаг с итоговой папкой и галочкой ярлыка описан в `build/installer.nsh`, боковая картинка мастера лежит в `build/installerSidebar.bmp` (164×314). Этот скрипт NSIS я не мог собрать на своей стороне; если сборка упадёт, `build-exe.bat` сам попробует ещё раз со стандартным мастером (тот же выбор диска и папки, ярлык создаётся всегда).

## Discord Rich Presence

Лаунчер сам общается с запущенным клиентом Discord, дополнительных программ не нужно. Нужен только Application ID:

1. Открой https://discord.com/developers/applications → «New Application» → назови, например, DLauncher (это название увидят друзья: «Играет в DLauncher»).
2. На странице «General Information» скопируй **Application ID**.
3. Rich Presence → Art Assets → загрузи квадратную картинку с именем `logo` (значок в статусе). Без неё статус работает, просто без значка.
4. В лаунчере: Настройки → Discord → включи галочку и вставь Application ID. Рядом появится состояние: «Жду запуска Discord…», «Подключено: ник».

Discord должен быть запущен на этом же компьютере (десктопная версия; браузерная не подходит). Если закрыть и снова открыть Discord, лаунчер переподключится сам в течение 15 секунд. Статус «Discord не принял Application ID» значит, что ID неверный.

## Сборка установщика на GitHub (без Node.js)

Если не хочешь собирать на своём компьютере, exe соберёт GitHub:
1. Загрузи все файлы проекта в свой репозиторий, включая скрытую папку `.github` (в ней `workflows/build.yml`). Если она не загрузилась перетаскиванием, создай файл кнопкой Add file → Create new file с именем `.github/workflows/build.yml` и вставь туда содержимое.
2. Открой вкладку **Actions** → **Build Windows installer** → **Run workflow**. Через несколько минут внутри запуска, в разделе Artifacts, появится `DLauncher-windows-x64` с установщиком и portable-файлом.
3. Чтобы выпустить версию для автообновления, создай релиз с тегом `v<версия>` (как в `package.json`, например `v1.6.0`). Тогда установщик, `latest.yml` и `.blockmap` прикрепятся к релизу сами, а лаунчер у людей скачает обновление.

Репозиторий для автообновления подставляется автоматически, спрашивать его не нужно.

## Автообновление

Работает только в установленной версии (`…-nsis.exe`), не в portable и не при `npm start`. Когда ты выкладываешь новую версию на GitHub, лаунчер у всех сам находит её и скачивает в фоне, ничего открывать не нужно. Устанавливается она, когда лаунчер закрывают (или по кнопке «Перезапустить» в уведомлении). Во время игры лаунчер не перезапускается.

**Один раз настрой:**
1. Создай репозиторий на GitHub (может быть публичным) и впиши его в `update-config.json` как `"repo": "ник/репозиторий"`. Можно ничего не править: `build-exe.bat` спросит репозиторий сам и сохранит ответ.
2. Запусти `build-exe.bat`.

**Чтобы выпустить новую версию:**
1. Подними `version` в `package.json` (например, `1.6.1`) и запусти `build-exe.bat`.
2. На GitHub: Releases → Draft a new release → тег вида `v1.6.1` (с `v` и той же версией, что в `package.json`). Прикрепи из папки `dist` три файла: `latest.yml`, `DLauncher-<версия>-x64-nsis.exe` и `…nsis.exe.blockmap`. Нажми Publish release (черновик не считается).
3. Всё. При следующем запуске (и затем раз в 3 часа, пока лаунчер открыт) у пользователей начнётся скачивание.

В Настройках → «Обновление лаунчера» можно отключить автопоиск или указать другой адрес (репозиторий GitHub либо папку на хостинге по HTTPS): он важнее зашитого в сборку. Если публикуешь без подписи кода, Windows SmartScreen может показывать предупреждение.

## Важно

- CurseForge требует бесплатный API-ключ: https://console.curseforge.com — вставь его в Настройках. Modrinth работает без ключа. У некоторых модов CurseForge автор запретил скачивание вне сайта — такие файлы в сборках пропускаются и показываются в итоговом сообщении.
- Legacy Launcher хранит игру в общей папке `.minecraft` — лаунчер находит её по стандартной структуре и по признакам `.tlauncher`. Если установлено много версий, при импорте можно выбрать нужную. OptiFine не поддерживается: такая версия импортируется как чистая игра.
- Импорт: новые версии Modrinth App хранят данные профилей в базе, поэтому версию игры у них прочитать нельзя — такие сборки лаунчер покажет в списке «не удалось прочитать». У официального лаунчера импортируется последняя запущенная версия вместе с общей папкой модов и миров.
- Аргументы Java в настройках профиля должны начинаться с «-». `-Xmx/-Xms` не принимаются: память задаётся ползунком.
- Статус серверов получается обычным запросом Minecraft (Server List Ping). Серверы за защитой от запросов могут показываться как «недоступен», хотя зайти на них можно.
- Быстрый вход: для версий 1.20+ используется `--quickPlayMultiplayer`, для старых — `--server/--port`.
- Шейдеры работают только с модом Iris (Fabric/Quilt) или Oculus (Forge). OptiFine не добавлен.
- Видео-фон: Electron играет MP4 с кодеком H.264 и WEBM (VP8/VP9). Если видео не запускается, перекодируй его в MP4 (H.264) или WEBM. Длинное видео в высоком разрешении заметно грузит видеокарту, а для слабых ПК лучше короткий ролик 1080p или картинка.
- Язык интерфейса: русский текст служит ключом, английский берётся из словаря в `i18n.js`. Если где-то остался русский текст на английском — это непереведённая строка, добавь её в словарь `EXACT` (или пришли мне).
- Новые функции (профили, Microsoft, сборки, NeoForge, автообновление, настройки профиля, серверы, Discord) писались без возможности запустить настоящий Minecraft и Microsoft/CurseForge — если что-то не сработает, пришли текст ошибки.
